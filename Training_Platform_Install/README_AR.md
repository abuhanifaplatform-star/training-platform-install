# صفحة تثبيت منصة التدريب

1. فك الضغط وارفع محتويات الحزمة إلى جذر مستودع مخصص في GitHub، مع إبقاء مجلد `icons` كما هو.
2. فعّل GitHub Pages من Settings ثم Pages، واختر النشر من الفرع `main` والمجلد `/ (root)`.
3. افتح رابط GitHub Pages على الجوال وأضفه إلى الشاشة الرئيسية وفق التعليمات الظاهرة في الصفحة.
4. تحقق من أن اسم الأيقونة «منصة التدريب» وأن رمز الشعار ظاهر، ثم افتحها واختبر زر «فتح المنصة».

الأيقونة تفتح صفحة التثبيت التي تحتوي زر «فتح المنصة». ينتقل الزر إلى رابط Google Apps Script المنشور، وقد يفتح المتصفح عند الانتقال إلى هذا الرابط.
